# Version v0.19.18

Improves CI transparency and robustness for automated release-note generation by making the selected LLM model visible and configurable.

## New Features

- Add support for an optional `RELEASE_NOTES_MODEL` repository variable to control which model is used for generating release notes, with a default fallback to `gpt-5.2`. (820934) (Cursor Agent)
- Echo the chosen release-notes model name in GitHub Actions logs to make CI behavior easier to diagnose. (820934) (Cursor Agent)

## Bug Fixes

- Avoid failures caused by the deprecated `gpt-4-turbo` secret being masked in Actions logs by no longer relying on `secrets.DEFAULT_LANGUAGE_MODEL` for release notes generation. (820934) (Cursor Agent)

## Deprecations

- Deprecate using `secrets.DEFAULT_LANGUAGE_MODEL` as the source of truth for the release-notes model in CI (superseded by `RELEASE_NOTES_MODEL` with a safe default). (820934) (Cursor Agent)
