# Version v0.19.14

This release includes several performance improvements and bug fixes that enhance the functionality and stability of the software, particularly in CI workflows and CLI operations.

## New Features

- Improved performance by deferring imports in the `llamabot` package, reducing initial load times significantly. (ea5c49d) (Eric Ma)
- Added a new method to approve parked workflow runs automatically on release PRs, enhancing CI workflow reliability. (5e68434) (Eric Ma)

## Bug Fixes

- Resolved issues with git path resolution in CLI tools to support worktree compatibility, ensuring tools work in various directory setups. (4787dff) (Eric Ma)
- Enhanced the stability of the release workflow by ensuring that version bumps are verified before proceeding with GitHub releases or PyPI publications. (467cef9) (Eric Ma)
- Fixed CI workflow to run tests on bot PRs, allowing auto-merge to complete without manual intervention. (aee4596) (Eric Ma)

## Performance Improvements

- Optimized import behavior in `llamabot` to defer heavy imports, significantly reducing the initial load time and improving overall performance. (b9d7388) (Eric Ma)
- Refined benchmarking in CI by introducing warmup and sampling strategies to provide more stable and accurate performance measurements. (b9d7388) (Eric Ma)

## Dependencies Updates

- Updated `prefix-dev/setup-pixi` from 0.10.0 to 0.10.1 to incorporate the latest fixes and improvements. (84951a4) (dependabot[bot])
- Upgraded `actions/setup-python` from version 6 to 7, aligning with the latest available features and improvements. (551e5c5) (dependabot[bot])
