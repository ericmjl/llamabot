# Version v0.19.14

This release includes significant improvements to the llamabot CLI and MCP performance optimizations, along with updates to dependencies and enhancements to the CI workflows.

## New Features

- Added a new helper function to resolve git paths, enhancing compatibility with git worktrees and allowing commands to run from any subdirectory. (4787dff) (Eric Ma)
- Implemented performance optimizations in llamabot by deferring imports of heavy modules, significantly reducing import times and improving responsiveness. (ea5c49d, 2028444, b9d7388) (Eric Ma)

## Bug Fixes

- Resolved issues with git paths in llamabot git hooks and compose commands to support linked worktrees and execution from subdirectories. (4787dff) (Eric Ma)
- Hardened the release workflow to handle silent push failures and ensure that version bumps and tags are correctly pushed to the main branch before proceeding with GitHub releases and PyPI publications. (467cef9) (Eric Ma)

## Performance Improvements

- Improved the stability of import benchmarks by adding a warmup phase and using minimum-of-three sampling to reduce variability on shared CI runners. (b9d7388) (Eric Ma)

## Dependency Updates

- Updated prefix-dev/setup-pixi from 0.10.0 to 0.10.1 to incorporate the latest changes and improvements. (84951a4) (dependabot[bot])
- Upgraded actions/setup-python from version 6 to 7, aligning with the latest available version for enhanced features and stability. (551e5c5) (dependabot[bot])
