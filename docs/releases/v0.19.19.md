# Version v0.19.19

This release refreshes model defaults and model listings to avoid retired provider IDs, and cleans up related documentation.

## New Features

- Updated the built-in Ollama model list to reflect current available models. (855ace) (ericmjl)
- Switched default LLM model IDs away from retired/sunsetting OpenAI and Mistral models to `gpt-5.2` for continued compatibility. (4f96f3) (Cursor Agent)

## Bug Fixes

- Removed a duplicated `gpt-5.2` example in the ToolBot reference docs caused by older examples collapsing to the same identifier. (df5db0) (Cursor Agent)

## Deprecations

- Deprecated the use of retired/scheduled-for-shutdown default model IDs (e.g., `gpt-4.1`, `gpt-4o`, `gpt-4o-mini`, `o1-preview`, `gpt-4-0125-preview`, `gpt-3.5-turbo-1106`, `mistral/mistral-medium`) by moving defaults to `gpt-5.2`. (4f96f3) (Cursor Agent)
