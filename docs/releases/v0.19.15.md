# Version v0.19.15

This release includes important updates to our continuous integration (CI) processes, enhancing the reliability and efficiency of our development workflow.

## New Features

- CI now runs the test matrix unconditionally on every pull request, ensuring all necessary checks are performed regardless of the type of changes made. This change addresses issues where documentation-only PRs were previously blocked due to skipped CI checks. (9689e5) (Eric Ma)

## Bug Fixes

- Fixed a critical issue where documentation-only pull requests were being blocked due to skipped CI checks. This fix ensures that all PRs, regardless of their content, trigger the required CI checks to proceed smoothly through the review process. (9689e5) (Eric Ma)

## Deprecations

- Removed unnecessary optimization in CI that skipped entire test matrices for documentation-only PRs, which previously led to blocked PRs and stalled releases. This streamlines our CI process and avoids future disruptions. (9689e5) (Eric Ma)
